# Mobile App Traffic Trace Collection and Analysis

Exam project for the **Computer Networks Fundamentals** course (Prof. Antonio Pescapè), Bachelor's Degree in Computer Engineering, University of Naples Federico II — A.Y. 2022/2023.

Group project (4 people), carried out at the Federico II's ARC LAB.

## What it's about

The report analyzes network traffic generated by mobile messaging, audio, and video call applications (**Discord, Google Meet, TrueConf, Jitsi Meet**), with the goal of studying traffic classification techniques (port-based, packet-based, flow-based, payload-based/DPI) and applying them to real data.

Project phases:
1. **Capture**: using the ARC LAB's tools (smartphones with a custom ROM, the **MIRAGE** capture software), 32 traffic sessions were recorded (chat, audio call, video call) across two pairs of students connected from different networks.
2. **Analysis**: the captured traces (`.pcap` files) were processed with **Capinfos**, **TShark**, and **Whois** to extract general information, TCP/UDP biflows, DNS resolutions, TLS SNI, HTTP hosts, and IP address metadata.
3. **Automation**: the analysis was automated with a bash script (included in this repository).

## Repository contents

- [`Elaborato RDC finale.pdf`](Elaborato%20RDC%20finale.pdf) — full report (in Italian): introduction, tools used, capture methodology, traffic analysis, experimental results, and conclusions.
- [`script.sh`](script.sh) — analysis automation script, described in Chapter 3 of the report. For each `traffic.pcap` trace it produces an `INFO.csv` file with general information (Capinfos), TCP/UDP biflows, DNS, SNI, and HTTP hosts (TShark), plus a whois analysis of the IP addresses involved (requires a `whois_commands.log` file with the list of IPs to query).

The script requires the original capture traces (`.pcap`) as input, which are not included in this repository.
